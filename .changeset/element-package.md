New package: a `<nurbling-avatar>` custom element for plain HTML, a CMS, Svelte, Solid, Angular or any page without a React, Vue or Astro component. Attributes mirror the core options, the `nurblings` property takes a `createNurblings` instance, and `@nurblings/element/define` registers it in one import.
