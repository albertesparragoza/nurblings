# example-astro

An Astro (TypeScript, static output) example that renders `@nurblings/astro`
avatars entirely at build time: a grid of avatars, a size row, a background
shape row, and one hover-animated avatar. The built page ships no
JavaScript.

## Run it

```sh
pnpm --filter example-astro dev
pnpm --filter example-astro build
```
